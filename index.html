飞机大战 · Airplane Battle

用 Pygame 写的复古太空射击：方向键躲、空格打、别让敌机撞上来。单文件、零配置、双击就跑。

下载 ZIP GitHub 仓库 README

30 秒上手

需要 Python 3.9+，唯一依赖是 pygame。

Windows

双击 run.bat：自动建虚拟环境、装依赖、开游戏。

macOS / Linux

chmod +x run.sh && ./run.sh

手动

pip install -r requirements.txt
python game.py

操作

没有鼠标，全是键盘。

移动 / 射击

←→↑↓ 移动飞船，空格 发射（100ms 冷却）。

状态

B 暂停 / 继续，V 静音，ESC 直接退出。

规则

5 条命，击毁一架 +100 分，被撞 -1 血并进入 800ms 无敌；敌机每 300ms 生成，最多 15 架。
